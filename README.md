# 🗳️ Voter Registration Form

A simple and responsive **Voter Registration Form** created using **HTML and CSS**. This project demonstrates the use of HTML forms, input fields, radio buttons, dropdown menus, file uploads, checkboxes, and basic CSS styling.

## 📌 Project Overview

This project provides a user-friendly form for collecting voter registration information.

The form is divided into several sections:

* **Personal Information**
* **Contact Information**
* **Address Information**
* **Identification Details**
* **Declaration**

The form includes required fields to ensure that users provide the necessary information before submitting.

## ✨ Features

* Clean and simple user interface
* HTML5 form elements
* Required field validation
* Personal information fields
* Date of birth selection
* Gender selection using radio buttons
* Mobile number and email fields
* Residential address input
* State selection dropdown
* District and pincode fields
* Identity document selection
* Document upload option
* Declaration checkbox
* Submit and Clear Form buttons
* CSS styling with centered form container and box shadow

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 🖥️ Form Sections

### 1. Personal Information

Users can enter:

* Name
* Father's / Mother's name
* Date of Birth
* Gender

### 2. Contact Information

The form collects:

* Mobile Number
* Email Address

### 3. Address Information

Users can provide:

* Residential Address
* State
* District
* Pincode

### 4. Identification Details

The form includes:

* Identity Document selection
* Identification Number
* Document Upload

### 5. Declaration

Users must confirm that the information provided is true and correct before submitting the form.

## 🎨 Styling

The form uses CSS to create a clean layout. The main form container has a white background, rounded corners, padding, and a box shadow. The page itself uses a light background color.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `voterform.html`.
4. The form will open in your web browser.

Alternatively, open the file directly in a browser such as Chrome, Edge, or Firefox.
